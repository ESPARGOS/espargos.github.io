Firmware News
Multi-beam TX beamforming now supported
New Feature 2026-10-17
ESPARGOS One now supports transmit beamforming with up to four simultaneous, independently steered beams. Each beam can carry its own waveform, with per-antenna amplitude, phase and delay control. This feature is only available to users with transmit authorization and requires firmware builds dated 2026-10-16 or later.
IQ sampling now supported
New Feature 2026-09-29
ESPARGOS One now supports phase-coherent capture of raw IQ samples without any hardware modifications. Update to the latest firmware from the dev channel to enable IQ sampling. See ESP-SDR for more details.
Control frame capture now works
New Feature 2026-08-21
ESPARGOS can now capture CSI from 802.11 control frames (such as acknowledgements), and control frame acquisition is configurable from the web interface. This feature is available in controller and sensor firmwares with build dates of 2026-08-21 and later.
CSI Streaming over USB and 802.11ax
New Feature 2026-04-27
The controller and sensor firmwares with build dates of 2026-04-27 and later received a major update. 802.11ax CSI with 4× the number of subcarriers is now supported, as well as streaming compressed CSI (exploits time-domain sparsity). This way, CSI as well as all settings and the whole web interface can be tunneled through UART. Make sure to update pyespargos to the latest version.
Controller update requires manual flashing
Manual Action 2026-02-26
If your controller is running a firmware with build date older than 2026-02-26 and you want to update to a version with build date newer than 2026-02-26, you must manually flash the new firmware using one of the recovery options (WebSerial or esptool). The reason for this change is a new partition table that is incompatible with older firmware versions.
New naming scheme for firmware channels
Notice 2026-02-26
Firmware channels were previously named latest and stable. The new naming scheme is dev (replaces latest), testing (replaces stable) and stable (new). The stable channel only contains firmware that has undergone manual testing, whereas dev and testing are outputs of the CI/CD pipeline.
Firmware publicly available
Done 2026-01-16
Firmware updates for ESPARGOS are now publicly available from this website, and are automatically updated using our CI/CD pipeline.

If you still have an older prototype version of ESPARGOS, please note that this hardware is no longer supported. You can, however, still download the last available firmware versions for this prototype hardware below. Prototype firmware is not updated anymore!

Update Instructions

Update directly from the internet with Web Update, or upload firmware files manually.

Web Update

Connect ESPARGOS via Ethernet with internet access. Open its web interface and click Update in the sidebar. See Setup for connection instructions.

  1. Choose the update channel.

    Choose stable for regular use, or testing or dev for newer builds. Leave the server and token fields as they are. Click Save Settings if you made changes.

  2. Check for updates.

    Click Check for Updates to see what is available. Use the Suggested Update Plan, which selects the components that need updating.

  3. Start the update.

    Click Start Web Update. The update takes around 5–10 minutes. Leave the page open and keep ESPARGOS powered and connected. It will reboot during the update. The page reconnects on its own.

  4. Check the firmware version.

    Once finished, reopen the Home page to check the installed versions under Firmware Version.

Manual Update in the Web Browser

Update all three components from the same channel: sensors first, then controller, then web assets. Wait for each update and reboot to finish.

Download the files above, then upload them under Update → Local Update in this order:

OrderFileField in Local UpdateButton
1espargos-sensor-firmware.binSensor application fileUpload Sensor App
2espargos-controller-firmware.binController app fileUpload Firmware
3espargos-controller-assets.binController assets partitionUpload Image

Command Line

# Download dev firmware files from espargos.net
cd /tmp
wget https://espargos.net/firmware/dev/espargos-sensor-firmware.bin
wget https://espargos.net/firmware/dev/espargos-controller-firmware.bin
wget https://espargos.net/firmware/dev/espargos-controller-assets.bin

# Upload firmware to ESPARGOS:
# * Change ESPARGOS_HOST to the IP address / hostname of your ESPARGOS device.
# * Make sure the update succeeded after every step. Otherwise, reboot ESPARGOS.
ESPARGOS_HOST=192.168.1.2
curl -# "http://$ESPARGOS_HOST/update_sensor_application" --compressed -H "Content-Type: application/octet-stream" --data-binary @espargos-sensor-firmware.bin | tee /dev/null
curl -# "http://$ESPARGOS_HOST/update_firmware" --compressed -H "Content-Type: application/octet-stream" --data-binary @espargos-controller-firmware.bin | tee /dev/null
curl -# "http://$ESPARGOS_HOST/upload_partition?partition=web" --compressed -H "Content-Type: application/octet-stream" --data-binary @espargos-controller-assets.bin | tee /dev/null

Recovery Instructions

Recovery images are only needed in case your ESPARGOS device is not functioning properly after a failed update. This way, you can always restore your device to a working state even if something goes wrong during the update process. A failed firmware update cannot "brick" ESPARGOS.

Manual Recovery with esptool

		

			
    
				
  • Make sure to install esptool. It is included in ESP-IDF, but full installation of ESP-IDF is not required.
    • 
				
  • Connect ESPARGOS to your computer via USB. It will appear as a USB serial device, assumed to be named /dev/ttyUSB0 in the following.
    • 
				
  • Execute the following command to flash the recovery image. This will reset ESPARGOS to factory settings:
    • 
				
    wget https://espargos.net/firmware/dev/espargos-controller-recovery.bin
esptool --chip esp32 -b 2000000 --before default-reset --after hard-reset write-flash --flash-mode dio --flash-size 16MB --flash-freq 40m 0x0000 espargos-controller-recovery.bin
