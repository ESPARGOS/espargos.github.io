ESPARGOS One

ESPARGOS One is a digital phased array for wireless research and applications in the 2.4 GHz band: eight phase-synchronized ESP32 chips, controlled and powered over Ethernet or USB. Work with WiFi channel state information (CSI) and coherent raw I/Q samples to explore wireless signals.

Available now from €350 (excl. VAT, EU-only).

WiFi CSI & Raw I/Q Reception

Capture phase-coherent WiFi channel state information (CSI) in real time, or use raw I/Q sampling at low duty cycle to study other signals in the 2.4 GHz band. Users with transmit authorization can also replay I/Q waveforms with transmit beamforming for experiments such as MIMO radar. See the Python documentation for examples and the firmware release notes for required versions.

Power over Ethernet

Avoid the hassle of running separate data, power and signalling cables: ESPARGOS is controlled over Ethernet, provides a simple web interface for configuration and can be powered from a power over ethernet (PoE) switch / injector. This makes ESPARGOS easy to use and deployments are quick to set up.

Python Library

With pyespargos, there is an easy-to-use library to control one or multiple ESPARGOS devices. Configure ESPARGOS with the built-in web interface, then use Python for CSI and I/Q capture and calibration. The python library comes with a collection of demo applications to get you started.

Technical Specifications

  • Reception

    • Designed for 2.402–2.482 GHz (2.4 GHz ISM band). Additional frequencies may be supported in I/Q mode.
    • Phase-coherent WiFi CSI for single-stream 802.11g/n/ax packets
    • WiFi CSI bandwidth: 20 MHz, or 40 MHz for 802.11n channel bonding
    • Raw I/Q samples synchronized across eight channels (low-duty-cycle capture)

  • Transmission & Radar

    Requires transmit authorization, e.g. an applicable amateur radio or other license.

    • WiFi packet transmission
    • I/Q waveform replay with TX beamforming for high array gain, supporting multiple simultaneous beams
    • Coherent transmit/receive operation for radar applications

  • Connectivity & Power

    • 100BASE-TX Ethernet with PoE for data / power
    • IEEE 802.3at Type 1 compliant PoE (class 3)
    • Power consumption: ~3.5 W

  • Antenna Array

    • 8× dual-polarized patch antennas (mixed linear / circular)
    • λ / 2 antenna spacing (60 mm)
    • Reference signal input / output for coherent multi-array setups
